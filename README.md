# Abner

A personal photography portfolio site, scaffolded with [Astro](https://astro.build).

Modeled loosely on the information architecture and interaction pattern of
high-end photography portfolios (category galleries, a lightbox viewer, a
simple about/contact) — with e-commerce, client proofing, and CMS admin
tooling intentionally left out for a first version.

> **Status:** scaffold in progress. Categories, images, and copy in this repo
> are placeholders and are expected to be replaced with real content.

## Getting started

```sh
npm install
npm run dev
```

More setup notes will land here as the scaffold is built out.
