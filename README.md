# Abner Soto

A personal photography portfolio site, built with [Astro](https://astro.build).

Modeled loosely on the information architecture and interaction pattern of
high-end photography portfolios (category galleries, a lightbox viewer, a
simple about/contact) — with e-commerce, client proofing, and CMS admin
tooling intentionally left out for a first version. Content is hand-edited
in the repo; there's no admin UI.

> **Status:** scaffold complete, content is placeholder. Categories,
> images, and copy in this repo are stand-ins and are expected to be
> replaced with real photography and copy — see "Replacing the placeholder
> content" below.

## Getting started

```sh
npm install
npm run dev
```

Other scripts:

```sh
npm run build         # production build to dist/
npm run preview       # preview the production build locally
npx astro check       # type-check .astro files and the content schema
```

Copy `.env.example` to `.env` to turn on optional features (currently: the
contact form's reCAPTCHA widget). Everything works without it.

## Project structure

```
src/
  content.config.ts        # 'galleries' content collection schema
  content/galleries/       # one folder per category; each item is a co-located
                            # markdown file + image (see below)
  data/categories.json     # category slugs/labels/order — drives /work routes
  components/              # Nav, Footer, Seo, MasonryGrid, GalleryCard, Lightbox
  layouts/BaseLayout.astro # <head>, Nav, Footer, global.css
  pages/
    index.astro            # home: hero + featured-work teaser
    work/index.astro        # category index
    work/[category].astro   # one gallery page per category
    about.astro
    contact.astro
  styles/global.css        # color/type/spacing tokens, masonry utility
scripts/generate-placeholders.mjs  # throwaway placeholder-image generator
```

## Content model

Each gallery photo is a markdown file sitting next to its image, e.g.:

```
src/content/galleries/portraits/006-golden-hour.jpg
src/content/galleries/portraits/006-golden-hour.md
```

```yaml
---
title: "Golden Hour"
category: "portraits"
order: 6
alt: "Describe the image for screen readers and SEO"
featured: false   # true pulls it into the homepage teaser
image: ./006-golden-hour.jpg
---
```

To add a photo: drop the image file and a matching `.md` file into the
right category folder. To add a whole new category: create the folder and
add an entry to `src/data/categories.json`.

## Replacing the placeholder content

Everything under `src/content/galleries/` right now was generated by
`scripts/generate-placeholders.mjs` — solid-color rectangles standing in
for real photos so the routing, masonry grid, and lightbox could be built
and tested end-to-end. Once real photography is ready:

1. Delete the placeholder `.jpg`/`.md` pairs (or a whole category folder)
   and add real ones following the content model above.
2. Delete `scripts/generate-placeholders.mjs` and the `placeholders` npm
   script — they're one-off scaffolding tools, not part of the site.
3. Replace the bio copy in `src/pages/about.astro` and swap its headshot
   image reference off the placeholder portrait it currently borrows.
4. Decide how `src/pages/contact.astro`'s form should actually submit
   (Netlify Forms, Formspree, or a plain `mailto:`) — it currently posts
   nowhere (`action="#"`, marked with a `TODO`).
5. Swap the palette/type tokens in `src/styles/global.css` for your own
   design direction if the placeholder look isn't what you want to keep.
